# Talentos Patria Milagro

Propuesta ejecutiva 2027 preparada como sitio web estático para GitHub Pages.

## Publicación manual en GitHub

1. Crea un repositorio público llamado `talentos-patria-milagro`.
2. Sube todos los archivos y carpetas de este paquete a la raíz del repositorio.
3. En GitHub, entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main** y la carpeta **/(root)**.
6. Pulsa **Save** y espera unos minutos.

El sitio quedará disponible en una dirección similar a:

`https://TU-USUARIO.github.io/talentos-patria-milagro/`

## Contenido

- `index.html`: sitio principal.
- `assets/`: imágenes y logos.
- `Talentos_Patria_Milagro_Propuesta_2027.pdf`: propuesta en PDF.
- `.nojekyll`: permite publicar el sitio sin transformaciones adicionales.
